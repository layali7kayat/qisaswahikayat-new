# قصص وروايات صوتية — مشروع مستقل للقصص الصوتية

هذا المشروع لا يعتمد على الموقع القديم أو Supabase. لا توجد قصص تجريبية. تظهر التصنيفات السبعة افتراضياً، وتبدأ القصص فارغة.

## مكونات المشروع
- `index.html` و`app.js` و`style.css`: الموقع العام.
- `admin.html` و`admin.js` و`admin.css`: لوحة الإدارة.
- `cloudflare/worker.js`: Cloudflare Worker API.
- `cloudflare/schema.sql`: مخطط D1 وإضافة التصنيفات السبعة.
- `netlify.toml`: إعداد نشر الموقع الثابت على Netlify.

## 1. إعداد Cloudflare للمشروع الجديد
استخدمي حساب Cloudflare الحالي، مع إبقاء موارد المشروع القديم كما هي. تم إنشاء Worker باسم `qisas-night-api` وقاعدة D1 باسم `qisas-night-db` ومخزن R2 باسم `qisas-night-media`.
1. افتحي إعدادات Worker `qisas-night-api` وتأكدي من وجود الربطين التاليين:
   - **R2 bucket binding** باسم `MEDIA`، وأنشئي bucket باسم مثل `qisas-night-media`.
   - **D1 database binding** باسم `DB`، وأنشئي قاعدة مثل `qisas-night-db`.
2. افتحي قاعدة D1 ثم Console، ويمكنك تنفيذ `cloudflare/schema.sql` لتأكيد وجود التصنيفات السبعة. لن تُضاف أي قصص تجريبية.
3. افتحي Worker → Edit code، واستبدلي كود الاختبار بمحتوى `cloudflare/worker.js` ثم اضغطي Deploy. هذا الكود متوافق مع جداول قاعدة البيانات التي أنشأناها بالفعل.
4. في Worker → Settings → Variables and Secrets أضيفي متغيرين سريين `ADMIN_EMAIL` و`ADMIN_PASSWORD`، واختاري بيانات دخول قوية وخاصة. لا تضعيها داخل ملفات الموقع.

## 2. نشر الموقع على Netlify
1. حمّلي ملف ZIP وافكي ضغطه.
2. أنشئي موقعاً جديداً في Netlify، ثم ارفعي مجلد المشروع `qisas-wa-hikayat-new` عبر خيار النشر اليدوي (Deploy manually) أو اربطيه بمستودع Git.
3. انتظري حتى يظهر عنوان مجاني ينتهي بـ `netlify.app`.
4. ملف `config.js` مضبوط مسبقًا على رابط Worker الحالي: `https://qisas-night-api.layali-7kayat-719.workers.dev`. إذا تغيّر الرابط مستقبلًا، حدّثيه ثم أعيدي نشر الموقع.
5. افتحي `admin.html` من عنوان الموقع وأدخلي البريد وكلمة المرور المطابقين لقيمتي `ADMIN_EMAIL` و`ADMIN_PASSWORD` في Cloudflare. تعديل `config.js` ضروري حتى يعمل الموقع عند جميع الزوار.

## 3. تجربة النشر
1. من لوحة الإدارة أضيفي عنواناً ووصفاً واختاري تصنيفاً.
2. ارفعي ملف MP3 وصورة JPG/PNG/WebP مربعة 1:1.
3. اضغطي «نشر القصة»، ثم افتحي الصفحة الرئيسية واختاري التصنيف للتأكد من ظهورها وتشغيل الصوت.

## تنبيهات مهمة
- ارفعي ملفات الصوت فقط بصيغة MP3. الحد المبرمج للملف الصوتي 100 ميغابايت والصورة 8 ميغابايت.
- كل صورة تصنيف اختيارية في البداية؛ يمكنك تعيينها من قسم «إدارة التصنيفات».
- يسمح Worker مبدئيًا بالطلبات من عناوين `*.netlify.app` و`localhost`. إذا ربطت نطاقًا مخصصًا، حدّثي `validOrigin` في Worker ليقبل نطاقك.
- يجب ضبط `config.js` بعنوان Worker الحقيقي وإعادة نشر الموقع؛ لا تتركي قيمة الرابط فارغة بعد الإعداد.
- لا تشاركي `ADMIN_PIN` أو أسرار Cloudflare. لا توجد كلمات مرور مضمّنة في ملفات الموقع.
- هذا إعداد أولي عملي؛ اختبريه بملف صوتي صغير قبل رفع ملفات كبيرة.


## إصلاحات إضافية
- إصلاح توقف JavaScript في لوحة الإدارة بسبب عناصر إعداد رابط API غير الموجودة في الصفحة.
- إضافة قاعدة CSS تضمن أن عناصر `hidden` تبقى مخفية، مما يساعد على فتح صفحة القصة الصحيحة بدل تداخل الأقسام.
- إزالة عنوان لوحة الإدارة من نموذج الدخول وتغيير تسمية القائمة إلى الأدمن.
- تعطيل قائمة النقر بالزر الأيمن وسحب الصور كتدابير ردع بسيطة. هذه التدابير لا تمنع نسخ المحتوى بشكل مضمون؛ أي ملف صوتي يُشغّل في المتصفح يمكن استخراجه تقنيًا، ويمكن تصوير الشاشة أو حفظ الصور بطرق أخرى.
